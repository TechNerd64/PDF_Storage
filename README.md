# PDF Storage

PDF Storage is a Python-utility that is meant to comply with the Hack Club Crescent theme "Weird Storage".  I was thinking of what would be quirky ways of storing and for some reason thought of PDFs.  So using Chat-GPT, I researched what was possible when it came to PDFs and generation them.  I then took my knowledge from this research and Harvard's CS50 to create encoder.py and decoder.py, along with a more user-friendly wrapper - main.py.  

## Encoding and Decoding
When pdf-storage encodes a file, it goes through all the byte data of the file and uses it to generate greyscale squares in the PDF to represent each and every byte.  It then stores the the original file name and extension in the PDF's metadata.  

The decoder than just parses the previously generated PDF essentially in reverse.  It first scans the PDF's metadata to ensure that the PDF file was correctly generated by the encoder, and that it isn't missing any needed data points.  It then just scans through the greyscale squares to regenerate the original file's byte code.


## Usage

PDF Storage uses the following command syntax:

```bash
python3 main.py <operation> <file>
```

### Encode

To encode a file into a PDF:

```bash
python3 main.py encode <input_file>
```

Example:

```bash
python3 main.py encode picture.png
```

This generates `picture.pdf` containing the encoded data.

### Decode

To recover an encoded file:

```bash
python3 main.py decode <input_pdf>
```

Example:

```bash
python3 main.py decode picture.pdf
```

This reconstructs the original file using its filename and metadata stored within the PDF.

## Building

PDF Storage can be compiled into a standalone Linux executable using PyInstaller.  This was the same method used to generate the compiled release.

Install PyInstaller:

```bash
python3 -m pip install pyinstaller
```

Build the executable:

```bash
pyinstaller --onefile --name pdf-storage main.py
```

The resulting executable will be located in `dist/`.

Usage with the compiled executable:

```bash
./dist/pdf-storage encode picture.png
./dist/pdf-storage decode picture.pdf
```
